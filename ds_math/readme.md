DS-Math: The Foundations from Scratch
This repository is a deep dive into the mathematical engine that powers modern Data Science and Artificial Intelligence. Following the philosophy of "Data Science from Scratch" (Joel Grus), I am building the core components of linear algebra, statistics, and probability using pure Python—zero dependencies, zero shortcuts.

Why Build Math from Scratch?
In an era of high-level abstractions like PyTorch and Scikit-Learn, true mastery belongs to those who understand the "black box." By implementing these concepts manually, I am mastering:

Vector and Matrix Mechanics: Moving beyond high-level functions to understand tensor operations.

Statistical Intuition: Coding the distributions and hypothesis tests that define data significance.

Optimization Logic: Implementing the gradients that drive machine learning convergence.

Core Modules
1. Linear Algebra (/linear_algebra)
The language of modern AI. Implementations include:

Vectors: Addition, subtraction, scalar multiplication, and dot products.

Matrices: Shape manipulation, and matrix multiplication logic.

Metrics: Distance calculations and magnitudes.
