# DataScienceFromScratch
This repository serves as a live documentation of my journey into the core of data science and machine learning. Unlike traditional paths that rely heavily on high-level libraries, my focus is on deep technical mastery—understanding the "why" before the "how." The primary resources are  O'reilly Standard data science books.

The Vision
My goal is to transition from a consumer of tools to a creator of systems. By manually implementing algorithms, I am building the mental and technical scaffolding required for elite engineering. This isn't just about getting code to run; it’s about understanding the underlying linear algebra, calculus, and optimization logic that powers modern AI.

Primary Learning Resources
I’ve moved away from fragmented tutorials in favor of the rigorous, industry-standard O’Reilly series. These "animal books" provide the theoretical depth and practical clarity necessary for professional-grade development. Key pillars of my current curriculum include:

Data Science from Scratch (Joel Grus): Building the fundamental toolkit from the ground up using pure Python.

Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow: Bridging the gap between fundamental concepts and production-ready frameworks.

Deep Learning with PyTorch: Mastering neural network architectures and tensor operations.

What’s Inside
Scratch Implementations: Clean, documented Python implementations of ML algorithms without the training wheels of external libraries.

Mathematical Foundations: Notes and scripts exploring the statistics and probability essential for data intuition.

Project Milestones: Real-world applications where I apply these "from scratch" concepts to solve complex data problems.

This repo is a testament to the belief that the best way to predict the future of AI is to build it—line by line.
